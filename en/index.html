01Askloyal · B2C → B2B · 2026Finance AI agent and deposit orchestrator8000users$600kAUM

Problem

Users kept dollars idle and decided by hand where to move them for yield. Slow, risky, and it does not scale to B2B partners.

What I built

  • An orchestrator that spreads deposits across pools for the best yield: up to 17% APY versus 7% in a regular bank, with no FX risk.
  • An LLM agent that proposes financial actions. Guardrails: it executes only what we marked safe, everything else needs confirmation.
  • Reliability: workers, retries, idempotency, daily reconciliation, alerts.
  • Integrations with B2B partners who bring their own customers.

Result

Launched in July, 2000 users in the first week, now 8000 users and $600k AUM. The code is open on GitHub.

      04

      How I work

      The same loop as in my projects. You will see it in the test task too.

      1. 01

        Talk to people

        First understand how the process works today and where it hurts. At my first job the users of my tool sat next door, the best feedback loop there is.

      2. 02

        Success criteria

        A metric and a check before code: what counts as success, on which data, and how we will notice a regression.

      3. 03

        Simple first

        The simplest version that delivers value. Then improve based on feedback, not the other way round.

      4. 04

        Agents + harness

        I write code with agents in an implement/verify loop. The harness rejects fabricated "done".

      5. 05

        Guardrails

        The agent can only do what is safe. Money, outgoing messages and deletions go through a person.

      6. 06

        Ship and measure

        Monitoring, alerts, A/B. Keep what worked and scale it.
